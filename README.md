# WorkshopLoader
Легкая и быстрая утилита для пакетной загрузки коллекций и отдельных модов из Steam Workshop

----

## Возможности

- Парсит страницу коллекции Steam и последовательно скачивает все моды.
- Под каждую коллекцию автоматически создаётся отдельная папка с её названием, а внутри - папки каждого мода с понятными именами вида `ID (Название)`.
- В папке с каждой коллекцией сохраняется файл `mods_links.txt` со списком прямых ссылок на все входящие в неё моды.
- Не требует ручной настройки - утилита сама скачивает и настраивает официальный клиент Valve при первом запуске.
- Если вы скачиваете один мод он создает специально папку "Single mod" и загружает туда моды. Если это коллекция, то создает папку с названием коллекции.

Протестированно на RimWorld
